INFO 5100 - Group Lab 1: Team 2

Project Overview

This project is part of INFO 5100 Application Engineering and Development.

The purpose of this lab is to practice GitHub collaboration, including creating branches, committing changes, pushing code, reviewing pull requests, and merging branches.

Project Description

Our team developed a Java greeting application using Apache NetBeans.

Each team member is responsible for creating a Java class that prints a personalized greeting message.

Technologies Used

Java

Apache NetBeans

GitHub

GitHub Desktop

Team Collaboration

Each member works on a separate feature branch. Changes are submitted through pull requests, reviewed by teammates, and merged into the main branch.
